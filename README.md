# Deriving the Brachistochrone Curve Using Calculus of Variations

A Year 1 Mathematical Investigations project at the University of Bristol studying the classical Brachistochrone problem.

## Overview

The Brachistochrone problem asks which curve allows a particle to travel between two points in the shortest time under uniform gravity.

This project uses calculus of variations to derive the curve that minimises the travel time. The total travel time is expressed as a functional of the curve, before applying the Euler–Lagrange equation to obtain a differential equation for the optimal path.

The resulting solution is reparameterised into the standard parametric form of a cycloid.
